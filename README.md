\# Навчальний сайт про котів



Це навчальний сайт про котів, створений для практики HTML і CSS. Він показує інформацію та зображення котів.



\## Встановлення і запуск



&#x20;Оберіть один із двох способів отримати файли проєкту.



\*\*Завантажити ZIP:\*\* відкрийте репозиторій на GitHub, натисніть \*\*Code → Download ZIP\*\* і розпакуйте завантажений архів.



\*\*Клонувати репозиторій:\*\* відкрийте термінал у потрібній папці та виконайте:



```bash

git clone https://github.com/ProKotik/arara-P2.git

```




\## Використання



Відкрийте папку проєкту, потім папку `AlienCats1` і файл `index.html` у браузері. Не переміщуйте зображення та інші файли з цієї папки, бо сторінка використовує їх.
!\[Структура папки проєкту](project-structure.png)
